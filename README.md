# CCYI Digital Academy

**Learn. Create. Innovate. Transform.**

The official website for CCYI Digital Academy — a digital skills training programme by CCYI Global Enterprise.

## 🎓 Courses

| Tier | Title | Focus |
|------|-------|-------|
| 1 | Introduction to Computers & Microsoft Office | Digital literacy and office productivity |
| 2 | Introduction to HTML & CSS | Building and styling web pages |
| 3 | Introduction to WordPress | Website design, management and publishing |
| 4 | Introduction to Artificial Intelligence | AI literacy, productivity and creativity |

## 🛠 Tech Stack

- **React** + **Vite** — fast, modern frontend
- **Tailwind CSS** — utility-first styling
- **React Router** — client-side routing
- **Lucide React** — icons
- **Vercel** — hosting and deployment
- **Moodle** — learning management system (external)

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 📦 Deployment

This project is configured for automatic deployment to Vercel:

1. Push this repository to GitHub
2. Import the repository in [Vercel](https://vercel.com)
3. Vercel will auto-detect Vite and deploy
4. Configure your custom domain (e.g., `academy.ccyiglobalentwebng.com.ng`)

## 🔗 Moodle Integration

The website connects to your Moodle LMS for:
- Student registration and enrolment
- Course access via the Student Portal
- Learning management, quizzes and assignments
- Certificate generation

Update the Student Portal link in `src/components/Navbar.jsx` with your Moodle URL.
